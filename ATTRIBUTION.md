# Attribution & Credits

Deen Companion is an open-source project that utilizes the UI design system, state preferences architecture, theme system, and core dependency structures of [Traffic Light](https://github.com/leekleak/traffic-light), a privacy-focused network manager built by [leekleak](https://github.com/leekleak).

We express our gratitude to the original developer for their clean codebase and elegant Jetpack Compose styling patterns.
